UYGULAMA:
1) GitHub > emirgasim/Salon-White1 > main
2) index.html içinde:

   satırının hemen altına index-additions.html içindeki İLK HTML BLOĞUNU ekle.
3) index.html içinde </body> etiketinden hemen önce:
   <link rel="stylesheet" href="experience-2.css">
   <script src="experience-2.js"></script>
   satırlarını ekle.
4) experience-2.css ve experience-2.js dosyalarını repository köküne yükle.
5) Commit changes.
6) Cloudflare GitHub build'i otomatik başlatacaktır.
